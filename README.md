# 🎮 Tic Tac Toe Game

A simple and interactive **Tic Tac Toe game built with JavaScript** as part of my JavaScript learning journey.

This project helped me practice JavaScript fundamentals by turning different concepts into a small, playable game.

## ✨ Features

* 🎮 Two-player Tic Tac Toe
* ❌ X and ⭕ O turns
* 🏆 Win detection
* 🤝 Draw detection
* 🔄 Restart game
* 📱 Simple and responsive interface

## 🧠 Concepts Practiced

* JavaScript Functions
* Arrays
* Conditional Statements
* DOM Manipulation
* Game Logic
* Basic problem-solving

## 🎯 What I Practiced

While building this project, I focused on understanding how different JavaScript concepts can work together to create something functional instead of practicing them separately.

The main challenge was implementing the **game logic** — checking the board after each move and determining whether there is a winner or a draw.

## 🚀 How to Play

1. Player X starts the game.
2. Players take turns selecting an empty cell.
3. Get three matching symbols in a row, column, or diagonal to win.
4. If all cells are filled without a winner, the game ends in a draw.
5. Use the **Restart Game** button to play again.
